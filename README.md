# Little Lab V4 — Research Expansion

A standalone illustrated scientific research game.

## New in this expansion
- 12 additional investigations (16 total) across biology, psychology, neuroscience, ecology, chemistry and conservation.
- Three-replicate runs, descriptive statistics by condition, control-variable guidance, CSV export.
- Existing island, laboratory, collectibles, grants, journal, decorations and save game remain.

## Installation
Upload `index.html` to the root of your GitHub Pages repository. No dependencies or build step. Existing V4 localStorage progress is preserved when used on the same domain.

Scientific measurements are simplified simulated educational values, not empirical data.
